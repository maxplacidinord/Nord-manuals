# NORD BU manuals

Automated collection of NORD BU-series manuals, preferring British English (`en`) over American English (`en-US`).

Source: https://www.nord.com/en/services/documentation/manuals/manuals.jsp

Run the **Collect NORD BU manuals** GitHub Actions workflow manually to populate `manuals/` and `manifest.csv`. Downloads are verified as PDFs and saved using `BU 0xxx - [title].pdf` naming. This archive is not affiliated with NORD DRIVESYSTEMS. Please respect NORD's copyright and distribution terms.
